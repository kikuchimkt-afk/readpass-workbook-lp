# アプリ名候補

仮採用：**ReadPass連動 かきこみワーク**

1. **ReadPass連動 かきこみワーク**

   ReadPassとの連携と、紙に書き込む教材であることが一度に伝わる。
2. **ReadPass 書いて読むワーク**

   筆写と音読を組み合わせる学習手順が自然に伝わる。
3. **ReadPass 読解筆写ノート**

   学習内容を端的に表し、落ち着いた教材名として使いやすい。
4. **ReadPass かいて復習ノート**

   アプリ使用後の定着教材という位置づけが分かりやすい。
5. **ReadPass 書く読解ワーク**

   短く覚えやすく、読解と筆写の両方を示せる。
6. **ReadPass 正しい英文を書くワーク**

   正解文の筆写を中心にする教材方針が具体的に伝わる。
7. **ReadPass 過去問かきこみノート**

   各試験回に対応する冊子であることを説明しやすい。
8. **ReadPass 読んで写すワーク**

   小学校高学年から中学生にも、行う作業を想像しやすい。
9. **ReadPass 手を動かす復習帳**

   アプリだけで終わらせない教材理念を穏やかに表現できる。
10. **ReadPass 学習定着ワーク**

    目的を広く伝えられ、他級へ展開しても使いやすい。

## 命名方針

- 英検公式教材と誤認させない。
- ReadPassと組み合わせる補助教材であることを明確にする。
- 10〜13歳の生徒にも「何をする教材か」が伝わる日本語を使う。
- 今後、ほかの試験回・級へ広げても使える名称にする。
