# PenPass

**副題：ReadPass連動 かきこみワーク**

PenPassは、ReadPassで解いた英語を、筆写・意味確認・和訳・音読で復習する教室教材の社内ライブラリです。

## 授業の流れ

1. **過去問プリントで解く**（目安25〜30分）― 全問を紙で解く。最終ページに正解一覧（解説なし）があるが、STEP1が終わるまで見ない
2. **ReadPassで答え合わせ・解説を読む**（目安12〜15分）― 正解を赤で書き、1問ごとに ○△× を付け、△と×の番号を書き出す
3. **PenPassで書く**（残り時間）― 書き出した △と× の番号だけを書く。終わらない分は宿題

PenPassは全問をやり切る教材ではありません。60〜80分の授業で全問を書き切ると授業時間を超えるため、
△と×に絞って分量を生徒ごとに調整し、残りを宿題に回す前提で設計しています。

生徒用ワークブックの1ページ目「きょうの進め方」に、この流れと△×の記入欄、
終了ライン、提出日欄をまとめています。指導教案の1ページ目には、
60分／80分のタイムテーブルと、生徒にそのまま読み上げる指示を載せています。

STEP1の過去問プリント（`type: "practice-exam"`）は、教材一覧の各回で生徒用ワークブックより前に表示されます。
ReadPass-Proが生成した大活字版の問題冊子で、最終ページに正解一覧（解説なし）が付くため、
「解答なし」ではなく「正解のみ・解説なし」として案内しています。

> この流れに対応済みなのは3級・準2級プラス・準2級（各2025年度第1〜3回、準2級プラスは2026年度第1回も含む）です。
> 4級・5級は、それぞれの生成スクリプトへ同じ改修を展開する必要があります。

### サポート版と標準版の違い

| | サポート版 | 標準版 |
|---|---|---|
| 大問1・2の写す文 | 書き出しと終わりの語を示す | 空所のある文・手がかりの文を自分でさがす |
| 大問3（3級）／長文（準2級・準2級プラス）の根拠文 | ページ下部の英文を見ながら写す | 本文から自分で探して、下を見ないで写す |
| 訳・確認見本 | 記入欄のすぐ上に見本。読んでから写す | 見ないで書く。書いた後にページ下部や見本と照合して赤で直す |

## 位置づけ

- 当校で授業を受講する生徒向けの無料学習特典
- 教材単体での販売・一般配布は行わない
- 現在は準2級プラスの2026年度第1回と、準2級プラス・準2級・3級・4級・5級の2025年度第1回〜第3回を収録
- 級 → 年度・回 → 生徒用／講師用の順に選ぶ構造
- 準2級プラス・準2級・3級は生徒用のサポート版・標準版と共通の指導教案、4級・5級は低学年向け共通版と指導教案を収録
- トップ画面から生徒向け紹介フライヤー（A4縦）をダウンロード可能

## ブランド・画面設計

- ブランドカラーはスカイブルー（`#36AFE7`）、濃色はネイビー（`#073B5C`）
- メインタイトルは筆記体の「PenPass」、直下に「ReadPass連動 かきこみワーク」と表記
- ヘッダーアイコンは、手でペンを持つ図柄を使用
- LPでは学習中の手元や授業準備の写真を大きく扱い、書いて学ぶ教材であることを伝える
- 教材一覧は、試験回を1行で表示し、選択時だけPDF一覧を展開する。級・年度・キーワードで絞り込める

## 教材の追加

`data/materials.json` に級・試験回・文書情報を追加し、PDFを `materials/<grade>/<exam>/` に置きます。
その後、カタログを再生成して検証します。

```powershell
npm.cmd run catalog
npm.cmd run check
```

HTMLには生成済みの教材リンクを保存するため、JavaScriptが無効でもすべてのPDFへ移動できます。
PDFの実ファイル名とダウンロード名は一致させ、`ReadPass_EIKEN_<級>_<年度-回>_<対象>_<版・教材種別>.pdf`の形式で登録します。

## ローカル確認

```powershell
npm.cmd run check
npm.cmd start
```

`http://127.0.0.1:4174` を開いて確認します。依存パッケージはありません。

`noindex` と `robots.txt` は検索エンジンによる発見を抑えるためのもので、認証機能ではありません。

## 公開サンプルについて

LPの紙面体験には独自例文だけを使用し、過去問題・選択肢・図版・問題レイアウトは掲載しません。実際のワークブックは教室内で案内します。

商標表示は、公益財団法人 日本英語検定協会の「知的財産権の取扱いに関する統一ガイドライン」に沿って記載しています。公開範囲を変更する場合は、事前に権利関係を再確認してください。
